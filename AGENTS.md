# AGENTS.md

This repository's agent guidance is maintained in a single canonical file:
[`CLAUDE.md`](./CLAUDE.md).

**Read `CLAUDE.md` for build/test commands, architecture, and conventions.**
It applies to any coding agent working in this repo, not just Claude Code.

A note on naming: ClawDEA is an IntelliJ plugin that wraps the **Claude Code CLI**
as a subprocess. References to "Claude" in `CLAUDE.md` describe that wrapped
product — they are accurate regardless of which agent is reading this file.
